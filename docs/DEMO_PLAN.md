# Suggested 20-Minute Live Demonstration

| Time | Demonstration |
|---|---|
| 0–2 min | Explain system users, data stored, sensitive encrypted field, and updated Section 2.3 security settings. |
| 2–5 min | Register a student and intentionally enter one invalid value; show validation, CAPTCHA, privacy consent, and OTP email. |
| 5–7 min | Verify the email OTP, then log in with password/CAPTCHA and complete login OTP. |
| 7–10 min | Submit incorrect login attempts and show the progressive lockout countdown and alert email. |
| 10–13 min | Use Forgot Password, answer the three security questions registered by the student twice, complete reset OTP, and change the password. |
| 13–15 min | Run `php scripts/monitor.php` from the terminal and explain the security flags. |
| 15–18 min | Open the admin dashboard and explain the summary cards, chart, top IPs, flags, filters, and read-only event list. |
| 18–20 min | Demonstrate student payment submission and cashier verification; explain that only verified payments count. |

Prepare working test accounts and inbox access before the demonstration. The instructor may ask you to explain selected code sections or implement a new requirement live; do not demonstrate features you cannot explain.
